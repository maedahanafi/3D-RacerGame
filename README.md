# Redline Run

A browser endless runner. Drive a red low-poly car down a sunny beach road, switch lanes, jump, and duck.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/).

## Controls

- Left / Right, or A / D: switch lanes
- Up, W, or Space: jump
- Down or S: duck
- Enter or Space on the title screen: start
- R, Enter, or Space after a crash: run again
- On a phone, use the on-screen pad

## Production build

```bash
npm run build
npm run preview
```
